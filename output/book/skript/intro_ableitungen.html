2  Differentiation

The numerical calculation of derivatives is demonstrated here using two approaches: first, as a difference quotient, and second, through polynomial fitting. These methods are applied, for example, when searching for extrema in experimental or simulation data, solving differential equations, or performing optimization procedures.

Although analytically computing a derivative is often much easier than integration, it is not directly possible in the cases mentioned above. The goal is always to find the derivative \(\mathsf{f'(x)}\) of a function \(\mathsf{f(x)}\) or of a discrete set of points \(\mathsf{(x_i, y_i)}\) at a specific location \(\mathsf{x=x_0}\) or over an interval.

The basic idea behind the difference quotients or difference formulas presented here is to approximate the function to be differentiated using a Taylor expansion at multiple points. This allows solving for the desired derivative at the corresponding expansion point.

2.1 Taylor Expansion

Using the Taylor expansion, any function \(\mathsf{f(x)}\) that is continuously differentiable any number of times can be approximated arbitrarily closely around an expansion point \(\mathsf{x_0}\). The functional dependence is now considered with respect to the variable \(\mathsf{h}\), which is only examined in the immediate vicinity of \(\mathsf{x_0}\). The Taylor expansion is given by:

\[ \mathsf{f(x_0 + h) = \sum_{i=0}^{\infty}\frac{1}{i!}f^{(i)}(x_0)\cdot h^i} \] \[ \mathsf{ = f(x_0) + f'(x_0)\cdot h + \frac{1}{2} f''(x_0)\cdot h^2 + \frac{1}{6}f'''(x_0)\cdot h^3 + \cdots} \]

This expansion can also be considered only up to a given order. For example, the expansion up to order \(\mathsf{ \mathcal{O}(h^3)}\) takes the form:

\[\mathsf{ f(x_0 + h) = f(x_0) + f'(x_0)\cdot h + \frac{1}{2} f''(x_0)\cdot h^2 + \mathcal{O}(h^3)} \]

Here, the Landau symbol \(\mathsf{\mathcal{O}}\) indicates the order, summarizing the neglected terms, here starting from \(\mathsf{h^3}\), as an approximation error. The order specifies how quickly or with which functional relationship the approximation error approaches zero as \(\mathsf{h \rightarrow 0}\).

A graphical representation of the first elements of the series further illustrates the basic idea. The following example expands the function

\[ \mathsf{f(x) = \sin(3x) + 2x} \]

around the point \(\mathsf{x_0=0.85}\).

def func(x, p=0):
    if p==0:
        return np.sin(3*x) + 2*x
    if p==1:
        return 3*np.cos(3*x) + 2
    if p==2:
        return -9*np.sin(3*x)
    if p==3:
        return -27*np.cos(3*x)
    return None

2.2 Difference Formulas

In this section, formulas for approximating derivatives by forming differences of func values are introduced. These formulas are all based on the Taylor expansion and can be formulated for arbitrary derivatives and orders. The simplest ones are presented here.

2.2.1 First Derivative, First Order

The simplest difference formula is obtained from the Taylor series up to \(\mathsf{\mathcal{O}(h^2)}\). Here, the series can be directly rearranged for the desired derivative at the point \(\mathsf{x_0}\).

\[\mathsf{f(x_0 + h) = f(x_0) + f'(x_0)h + \mathcal{O}(h^2)} \] \[\mathsf{\Rightarrow \quad f'(x_0) = \frac{f(x_0 + h) - f(x_0)}{h} + \mathcal{O}(h)} \]

This is the forward difference formula of first order for the first derivative.
First order means that in the limit \(\mathsf{h\rightarrow 0}\) the approximation error decreases linearly with the step size.

According to this formula, the func to be differentiated must be evaluated at two points \(\mathsf{f(x_0)}\) and \(\mathsf{f(x_0+h)}\) in order to determine the derivative numerically. In the limit of an arbitrarily small step size, i.e. \(\mathsf{h \rightarrow 0}\), this quotient approaches the exact derivative at the point \(\mathsf{x_0}\).

The following example demonstrates the approximation using the func

\[ \mathsf{f(x) = \sin(3x) + 2x} \]

The derivative is approximated at the point \(\mathsf{x_0 = 0.85}\).

def func(x):
    return np.sin(3*x) + 2*x

# Data for visualization
x = np.linspace(0, 2, 100)
y = func(x)

# Exact solution at x=0.85
fp_exactly = 3*np.cos(3*0.85) + 2
# Expansion point and step size
h = 0.25
x0 = 0.85

# Evaluation at the two points
f0 = func(x0)
fh = func(x0 + h)

# Determination of the derivative approximation
fp = (fh - f0) / h
print(f"The numerical approximation of the derivative at the point {x0:.2f}:")
print(f"Approximation with step size {h:.2f}: {fp:.2f}")
print(f"Exact value: {fp_exactly:.2f}")
The numerical approximation of the derivative at the point 0.85:
Approximation with step size 0.25: -0.86
Exact value: -0.49

The method can also be illustrated graphically. The desired slope is the slope of the straight line shown in the plot.

plt.plot(x, y, label="Function")
plt.scatter([x0], [f0], color='C3', label='Expansion point', zorder=3)
plt.scatter([x0+h], [fh], color='C4', label='Evaluation points', zorder=3)

plt.vlines(x0, ymin=0, ymax=f0, color='C3', alpha=0.5)

plt.plot(x, f0 + fp*(x-x0), label='Difference formula')

plt.xlabel('x')
plt.ylabel('y')
plt.grid()
plt.legend(bbox_to_anchor=(1.05, 1.0), loc='upper left');

2.2.2 Second-Order First Derivative

Using the same approach, a second-order difference formula can also be derived. For this, the func is approximated at the points \(\mathsf{x_0-h}\) and \(\mathsf{x_0+h}\) using the Taylor series up to order \(\mathsf{\mathcal{O}(h^3)}\).

\[\mathsf{f(x_0+h) = f(x_0) + f'(x_0)\cdot h + \frac{1}{2}f''(x_0)\cdot h^2 + \mathcal{O}(h^3)} \] \[\mathsf{f(x_0-h) = f(x_0) - f'(x_0)\cdot h + \frac{1}{2}f''(x_0)\cdot h^2 + \mathcal{O}(h^3)} \]

The difference between these two equations gives

\[\mathsf{f(x_0+h) - f(x_0-h) = 2f'(x_0)\cdot h + \mathcal{O}(h^3)} \]

Rearranging for the derivative at the point \(\mathsf{x_0}\) yields

\[\mathsf{f'(x_0) = \frac{f(x_0+h) - f(x_0-h)}{2h} + \mathcal{O}(h^2)} \]

This is the central difference formula for the first derivative with second-order accuracy. As with the forward formula, the func must be evaluated at two points, but not at the expansion point itself. This symmetry around the expansion point results in improved convergence behavior, which is quadratic in this case.

# Evaluate the func at both points
fmh = func(x0 - h)
fph = func(x0 + h)

# Compute the derivative approximation
fp = (fph - fmh) / (2*h)
print(f"The numerical approximation of the derivative at the point {x0:.2f}:")
print(f"Approximation with step size {h:.2f}: {fp:.2f}")
print(f"Exact value: {fp_exactly:.2f}")
The numerical approximation of the derivative at the point 0.85:
Approximation with step size 0.25: -0.26
Exact value: -0.49

The method can also be represented graphically. The slope sought is the slope of the straight lines drawn.

plt.plot(x, y, label="Function")
plt.scatter([x0], [f0], color='C3', label='Expansion Point', zorder=3)
plt.scatter([x0-h, x0+h], [fmh, fph], color='C4', label='Evaluation Points', zorder=3)

plt.vlines(x0, ymin=0, ymax=f0, color='C3', alpha=0.5)

plt.plot(x, fmh + fp*(x-x0+h), label='Difference Formula')

plt.xlabel('x')
plt.ylabel('y')
plt.grid()
plt.legend(bbox_to_anchor=(1.05, 1.0), loc='upper left');

2.3 Second-Order Derivative

Using the same scheme as above, the finite difference formula for the second derivative can also be determined. It is given by

\[\mathsf{f''(x_0) = \frac{f(x_0-h) - 2f(x_0) + f(x_0+h)}{h^2} + \mathcal{O}(h^2)}\]

2.4 Error Analysis

In this section, approximation errors, i.e., errors arising from difference formulas, and rounding errors, i.e., errors due to the finite precision of digital number representation, are considered.

2.4.1 Approximation Error

The order of the method can be determined by analyzing the error, here with respect to the known exact value. For this purpose, the step size is continuously reduced.

Code 
def fkt(x):
    return np.sin(3*x) + 2*x

# Data for visualization
x = np.linspace(0, 2, 100)
y = fkt(x)

# Exact solution at x=1
fp_exact = 3*np.cos(3*0.85) + 2
Code 
x0 = 0.85

hs = []
fpfs = []
fpcs = []

h0 = 1
for i in range(18):
    h = h0 / 2**i

    f0 = fkt(x0)
    fnh = fkt(x0 - h)
    fph = fkt(x0 + h)

    fpf = (fph - f0) / h
    fpc = (fph - fnh) / (2*h)
    
    hs.append(h)
    fpfs.append(fpf)
    fpcs.append(fpc)
Code 
plt.plot(hs, np.abs(fpfs - fp_exact), label='forward')
plt.plot(hs, np.abs(fpcs - fp_exact), label='central')

plt.plot([1e-5, 1e-1], [1e-5, 1e-1], '--', color='grey', label='guide lines')
plt.plot([1e-5, 1e-1], [1e-10, 1e-2], '--', color='grey')

plt.xlabel('Step size h')
plt.ylabel('Error')

plt.xscale('log')
plt.yscale('log')

plt.legend()
plt.grid();

In the logarithmic representation of both axes, power functions become straight lines with the exponent as the slope. This means that the error in the above plot behaves like a power function of degree one and two, respectively. The auxiliary lines that are drawn have slopes of one and two, respectively. This also corresponds to the order \(\mathsf{\mathcal{O}(h)}\) and \(\mathsf{\mathcal{O}(h^2)}\) from the difference formula.

2.4.2 Rounding Errors

If the step size is reduced even further, the precision of number representation, i.e., rounding errors, begins to affect the approximation.

Code 
x0 = 0.85

hs = []
fpfs = []
fpcs = []


h0 = 1
for i in range(35):
    h = h0 / 2**i

    f0 = fkt(x0)
    fnh = fkt(x0 - h)
    fph = fkt(x0 + h)

    fpf = (fph - f0) / h
    fpc = (fph - fnh) / (2*h)
    
    hs.append(h)
    fpfs.append(fpf)
    fpcs.append(fpc)

plt.plot(hs, np.abs(fpfs - fp_exact), label='forward')
plt.plot(hs, np.abs(fpcs - fp_exact), label='central')

plt.plot([1e-5, 1e-1], [1e-5, 1e-1], '--', color='grey', label='reference lines')

As previously introduced, 64-bit numbers can only be represented with a precision of approximately \(\mathsf{\epsilon\approx10^{-16}}\). This means that, for example, the difference between two numbers cannot be computed more accurately than \(\mathsf{\epsilon}\). This is the so-called rounding error.

In the specific case of the forward difference formula, this implies:

\[ \mathsf{f'(x_0) = \frac{f(x_0 + h) - f(x_0)}{h} + \mathcal{O}(h)} \] \[\mathsf{\overset{rounding\ error}{\Rightarrow} \frac{f(x_0 + h) - f(x_0) + \mathcal{O}(\epsilon)}{h} + \mathcal{O}(h)} \] \[ \mathsf{= \frac{f(x_0 + h) - f(x_0)}{h} + \mathcal{O}\left(\frac{\epsilon}{h}\right) + \mathcal{O}(h)} \]

Hence, reducing \(\mathsf{h}\) only makes sense as long as the rounding error is small compared to \(\mathsf{h}\). More precisely:

\[\mathsf{\frac{\epsilon}{h} \le h }\] \[\mathsf{\Rightarrow \quad h \ge \sqrt{\epsilon}} \]

With \(\mathsf{\epsilon \approx 10^{-16}}\), for this difference formula, a \(\mathsf{h}\) is only reasonable down to about \(\mathsf{10^{-8}}\).
